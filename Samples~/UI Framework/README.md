# UI Framework Examples

本示例包含 UI Framework 常用界面脚本、Prefab 和配套字体资源。

- `UIHome`：主页界面
- `UIMenu`：菜单及按钮状态示例
- `UIHelp`、`UITitlebar`：帮助与标题栏
- `UIPrompt`、`UIQuestion`：提示与题目界面
- `UILoadScene`、`UIWaiting`：场景加载与等待界面
- `UIRBButton`、`UITopTip`：单选按钮与顶部提示
- `UINewbieGuide`：支持点按、精确文字框选和拖放演示的新手引导

## UIQuestion 依赖

`UIQuestion` 使用 Cowart Configuration Tools 的题目数据类型和 Cowart Object Tools 的预制体生成器。导入本示例前，请先安装这两个包。

## UINewbieGuide 依赖

`UINewbieGuide` 使用 DOTween 播放引导动画。导入本示例前，请先在项目中安装并初始化 DOTween。
